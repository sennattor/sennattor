# Quantitative Portfolio

This directory contains my public projects in quantitative finance, risk, modelling, and data engineering.

## Projects

### [Simple Trading Bot](./simple-trading-bot)

A compact Python backtest of a long/cash moving-average crossover strategy.

**Focus:** strategy implementation, backtesting discipline, transaction costs, look-ahead-bias prevention, and performance analytics.

**Current metrics:** Total Return, CAGR, Sharpe Ratio, Maximum Drawdown, Number of Trades, and Buy-and-Hold comparison.

**Stack:** Python, pandas, NumPy, yfinance.
